In this entry I will present two computational problems and discuss the corresponding complexity classes. This may sound like a lowly goal even for an introductory post, but we will see that even these basic definitions will culminate into the infamous P = NP question, which is the most important unresolved question in theoretical computer science. 

### Two problems from logic

Let us begin by presenting two computational logic from propositional logic. In propositional logic the basic building blocks are *atoms*, or *propositional variables*, which can be either true (1) or false (0). One can then combine atoms with logical connectives, $$\neg$$, $$\land$$, $$\lor$$, $$\leftarrow$$, and so on, to form more complicated propositions whose truth values hinge on the truth values of the involved propositional variables. For example, under the usual definitions of $$\land$$, $$\neg$$, and $$\rightrarrow$$, the propositional formula $$(x \land \neg y) \rightarrow z$$ is false if $$x$$ is true, $$y$$ is false, and if $$z$$ is false, and is true otherwise. Given a propositional formula one may for example wish to know whether it is **satisfiable**, a **tautology**, or a **contradiction**.

**The Boolean Satisfiability Problem (SAT) **

Instance: A propositional formula $$\phi$$.

Question: Is $$\phi$$ satisfiable, i.e., does there exist an assignment to its variables which makes it true?

So why is this useful? In a logic course, propositional logic is typically viewed as a stepping stone towards the much richer first-order logic, but if one is interested in studying computational aspects of the problems, it is worth to make a longer stop at the propositional case. Thus, does the SAT problem seem worth studying from a computational perspective, or is it too restricted to be of interest? How much can we really express in propositional logic? The answers turns out to be: quite a bit. Here, the key idea is to think in terms of encodings

The first thing that a complexity theorist attempts to do when faced with a new problem is to place the problem in a suitable complexity class. We may immediately observe that a SAT instance can be solved by (1) enumerating all possible truth assignments of its variables, and (2) for each such assignment, check whether it satisfies the instance. The second step can easily be accomplished by a simple evaluation procedure which recursively evaluates each subformula. This implies that SAT is solvable in exponential time, with respect to the number of propositional variables, and we thus see that SAT is included in EXPTIME: the class of problems solvable in exponential time (with respect to a reasonable underlying computational model, e.g., a Turing machine, as discussed in the previous entry).

But is this the end of the story? In that case, it sounds rather easy to be a complexity theorist: propose a naive method to solve the problem and then define a complexity class which uses this time bound as the constraining resource. Fortunately, this is not the entire story, and complexity theory is a much richer field than what the above might suggest. Thus, while it is indeed true that SAT belongs to EXPTIME, it turns out that there is a (probably smaller) complexity class which better describes the complexity of SAT. And the key idea behind this complexity class has actually already been presented in this paragraph: given a propositional formula and a truth assignment to its variables, it is possible to efficiently (in polynomial time) verify whether the assignment satisfies the formula or not. Another way to phrase this property is that we in the context of SAT can efficiently verify whether a claimed proof (of a satisfying assignment) is actually a proof or not. This property might not sound terribly impressive but will turn out to be absolutely crucial for developing a suitable complexity class capturing all the nuances of the SAT problem. But before we continue, let us just verify that this property is not something one can take for granted, and is actually non trivial. A straightforward example for this purpose is to consider the variant of SAT where the want to determine whether the input formula is a tautology or not. Thus, given a formula and an assignment to its variables, is it possible to efficiently verify whether the formula is a tautogoly or not? If it turns out that the assignment does not satisfy the formula, then we can clearly just answer **no**, but if the assignment satisfies the formula then we are none the wiser, since we do not know whether there exists another assignment which satisfies the formula or not. This example might sound artificial but there are many computational problems where proofs cannot, or is not known to, be verifiable in polynomial time.	

With this insight we then define our new complexity class as the set of all decision problems where it is possible to verify proofs in polynomial time. Hence, this class includes SAT, and hopefully other problems which at least in some sense are similar to SAT.
